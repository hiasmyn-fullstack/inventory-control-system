# 📦 Inventory Control System

A complete inventory management system built with **Python**, **Flask**, and **SQLite**.  
This project implements full CRUD functionality and follows best practices for backend development.

---

## ✨ Features

- ✅ **Register products** — Add new items with name, quantity, and price
- 📋 **List all products** — View complete inventory in a clean table
- ➕ **Stock entry** — Increase product quantity
- ➖ **Stock exit** — Decrease quantity, **never below zero**
- 🗑️ **Delete products** — Remove items with confirmation prompt
- ⚠️ **Low stock alert** — Yellow warning row when quantity ≤ 3
- 📱 **Responsive design** — Built with Bootstrap 5

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|

| SQLite | Lightweight database |
